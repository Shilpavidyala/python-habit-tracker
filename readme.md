# Multi-Metric Habit & Goal Tracker 🎯

An interactive data-driven web application built with Python and Streamlit to log, track, and analyze daily habits and target goals.

## 🚀 Features
- **Multi-Metric Logging**: Track boolean completion, custom numeric targets, and duration metrics.
- **Data Persistence**: Local storage handling via structured JSON logging.
- **Interactive Visualizations**: Dynamic progress metrics and analytical summary dataframes.

## 🛠️ Tech Stack
- **Language**: Python 3
- **Framework**: Streamlit
- **Data Processing**: Pandas
